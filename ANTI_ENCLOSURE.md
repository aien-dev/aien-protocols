# AIEN Anti-Enclosure Commitments

These commitments govern the AIEN standards process and protocol ecosystem:

1. Published AIEN protocols remain publicly implementable by any party without fee or royalty.
2. Conformance does not require use of an AIEN reference implementation or proprietary runtime.
3. Contributed patent rights essential to protocol implementation are handled under the Community Specification License 1.0 regime.
4. Reference implementations remain protected by their respective open and copyleft licenses (MPL-2.0, AGPL-3.0-only).
5. AIEN trademarks indicate authentic conformance, provenance, and interoperability, not exclusive implementation rights.
6. No entity or vendor receives privileged access to secret versions of the canonical ABI.
7. Canonical specifications, schemas, conformance suites, and version history remain publicly accessible to humanity.
8. Anti-Enclosure Covenant on Model Weights: Any derivative model weights, adapters, or distilled artifacts trained or optimized using canonical AIEN ABI implementations or protocols must remain openly accessible and cannot be locked behind proprietary gating, closed API enclosures, or exclusive paywalls. Conformant implementations must reject enclosures that restrict model weight distribution to the sovereign commons.
