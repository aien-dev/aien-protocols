# Working Group Scope

The scope of this Working Group encompasses:
- Canonical data models and state machines for autonomous agent execution state, context lineage, and memory references (Agent State ABI).
- Wire contracts and streaming protocols for accelerator-agnostic inference services, KV cache branching, and leased pinning (Inference Protocol).
- Verifier contracts, evidence envelopes, and attestation receipts for autonomous candidate evaluation (Evaluation Protocol).
- Side-effect requests, capability grants, and execution confinement receipts (Action Protocol).
